# تأكد

الفكرة جتني بعد ما كثرت الاشاعات، والناس صارت تنشر الأخبار وتصدقها بدون ما تتأكد من الجهات الرسمية.

فقلت ليش ما أجمع الحسابات الرسمية في مكان واحد؟ عشان أي أحد يقدر يتأكد بنفسه قبل لا يصدق أو ينشر.

الموقع: https://xmillon.github.io/Taakkad/

كل الروابط أخذتها من المواقع الرسمية للجهات، وفتحتها بنفسي قبل لا أضيفها. وتحت كل جهة تاريخ آخر مرة تحققت منها.

وإن شاء الله بضيف جهات وحسابات رسمية جديدة مع الوقت.

وأوصي الكل ياخذون أخبارهم من المصادر الرسمية بس.

لو لقيت رابط غلط أو جهة ناقصة، افتح Issue وأشوفه.

مبادرة شخصية، مو جهة رسمية.
